# Horror at the Harvest Festival

A Foundry VTT content module for the **Legend in the Mist** system
(`mist-engine-fvtt` 14.5.0 or later), Foundry v13 or later.

Table-side content for one Narrator's run of the one-shot: Challenges, Journeys,
six pregenerated Heroes, a Fellowship theme, gridless scenes, handouts and cue cards.

Generated content. Do not edit anything here by hand; it is rebuilt from an
Obsidian vault and every change will be overwritten.

## Install

Foundry: **Add-on Modules**, **Install Module**, and paste this into **Manifest URL**:

```
https://synth-rabbit.github.io/horror-at-the-harvest-festival-module/module.json
```

On Sqyre: game detail page, **MANAGE GAME**, **Manage Modules**, same field.

Then enable the module in your world and open **Start Here** in the Narrator Notes pack.

Version 0.2.1.
